# Repository Guide

The repository is one canonical release tree for both archival distribution
and public hosting.

## Root Layout

- `README.md`: release overview and quick verification.
- `LICENSE`: anonymous-review license holder and license terms.
- `requirements.txt`: CPU analysis/test environment.
- `requirements-analysis.txt`: analysis and test dependencies.
- `requirements-gpu.txt`: model, training, and feature-extraction dependencies.
- `data/`: canonical synthetic datasets and experiment configuration inputs.
- `artifacts/`: immutable released numerical evidence and figures.
- `src/`: core dataset, evaluation, geometry, and compiler modules.
- `scripts/`: orchestration, analysis, and figure/table entry points.
- `tests/`: CPU contracts for data, scorers, artifacts, and release integrity.
- `docs/`: methodology and reproduction documentation.

## Canonical Data

- `data/latent_specs.jsonl`: 600 synthetic learning specifications.
- `data/prompt_examples.jsonl`: canonical prompt examples and scoring metadata.
- `data/calibration_manifest.jsonl`: historical Llama calibration plan.
- `data/compiler/`: Llama compiler episode/configuration inputs.
- `data/compiler_gemma/`: Gemma compiler configuration inputs.

The flat prompt CSV is a convenience export generated by
`src/generate_dataset.py`; retained workflows use the canonical JSONL.

## Released Evidence

`artifacts/README.md` provides the complete artifact map. In brief:

- `artifacts/llama/`: primary compiler evidence.
- `artifacts/llama/calibration/`: current Llama Table 1 schedule evidence.
- `artifacts/gemma/`: corrected Gemma replication evidence, including the
  independent calibration supporting current Table 12.
- `artifacts/localization/`: primary and robustness localization evidence.
- `artifacts/figures/`: figure sources and released figures.
- `artifacts/MANIFEST.csv`: release paths, sizes, hashes, roles, provenance,
  scorer versions, and regeneration commands.

The earlier localization calibration figures and transferred-budget Gemma
sensitivity outputs are historical and intentionally absent from this
current-paper release.

## Source and Scripts

Core modules under `src/` implement deterministic dataset construction,
evaluation, result summarization, geometry construction, prediction, and
selection. Runnable entry points are grouped under `scripts/reproduce/`,
`scripts/experiments/`, `scripts/audits/`, and `scripts/maintenance/`; see
`scripts/README.md` for the directory map.

Normal CPU verification neither downloads models nor runs adaptation. GPU
workflows are opt-in and always write to `outputs/`.
